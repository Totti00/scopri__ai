# Scopri AI

Contenuti per la pagina Instagram **[@scopri__ai](https://www.instagram.com/scopri__ai/)**: l'intelligenza artificiale che funziona davvero.

| Cartella | Cosa contiene |
|---|---|
| `CLAUDE.md` | Le regole che Claude segue per ogni post |
| `brand/` | Nome, bio, colori, font, tono di voce |
| `format/` | Le rubriche fisse: struttura delle slide e della caption |
| `calendario.md` | Quando esce cosa |
| `fonti.md` | Le fonti affidabili, in ordine di priorità |
| `ispirazione/` | Analisi dei concorrenti (cosa prendere, cosa evitare) |
| `archivio/` | Ogni post pubblicato: slide, caption, fonti |

**Flusso:** Claude prepara slide e caption → il proprietario le controlla e pubblica a mano su Instagram (aggiungendo la musica se vuole).
